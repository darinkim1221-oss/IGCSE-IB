# 금융 개념 게임 디자이너 스킬

## 목적

경제·금융 개념을 아이들의 뇌에 깊이 박히게 하는 게임으로 변환한다.
단순한 "재미"가 아니라 **개념을 몸으로 체험하게** 하는 것이 핵심.

> 핵심 철학: 아이가 게임을 하는 동안 "이게 사실 공부였어?" 라고 느낄 때, 가장 깊은 학습이 일어난다.

---

## 입력 정보 수집

스킬 실행 전, 다음 정보가 없으면 먼저 물어본다:

1. **개념**: 어떤 금융/경제 개념인가? (예: 복리, 기회비용, 인플레이션)
2. **연령대**: 10~12세(초고) / 13~15세(중등) / 혼합
3. **게임 형태**: 디지털 미니게임 / 보드·카드게임 / 퀴즈쇼 / 자유 선택
4. **수업 맥락**: 수업 시간(몇 분?), 인원(개인/팀), 준비물 제약 있는지

---

## 게임 설계 프레임워크

### 1단계: 개념의 "핵심 긴장감" 찾기

모든 좋은 게임에는 **긴장감(tension)**이 있다. 금융 개념의 본질적 긴장감을 먼저 추출한다.

| 개념 | 핵심 긴장감 |
|------|------------|
| 복리 | 지금 쓸까 vs. 나중에 더 받을까 |
| 인플레이션 | 돈의 가치가 녹아내리는 공포 |
| 수요·공급 | 갖고 싶은 사람 많을수록 값이 오른다 |
| 기회비용 | A를 선택하는 순간 B는 영원히 사라진다 |
| 주식투자 | 불확실성과 기대 수익 사이의 줄다리기 |
| 예산 관리 | 원하는 것 > 가진 것, 무엇을 포기하나 |

→ 이 긴장감이 게임의 **핵심 메카닉**이 된다.

---

### 2단계: 게임 형태별 설계 가이드

#### 🎮 디지털 미니게임 (웹/앱)

**설계 원칙:**
- 30초 안에 규칙을 파악할 수 있어야 한다
- 즉각적인 피드백 (숫자, 효과, 소리)
- 반복 플레이 가능한 루프 구조

**결과물 구성:**
```
[게임 기획서]
- 게임명 + 한 줄 소개
- 핵심 메카닉 (게임의 핵심 행동 1~2가지)
- 화면 구성 설명 (UI 스케치 or 텍스트 묘사)
- 라운드 구조 (몇 라운드? 각 라운드에서 무슨 결정?)
- 점수/결과 시스템
- 개념 연결 포인트 (이 메카닉이 어떻게 개념을 가르치는가)

[튜터 가이드]
- 플레이 전 브리핑 (1분)
- 플레이 후 디브리핑 질문 3가지
- 흔한 오해와 정정 방법
```

---

#### 🃏 보드게임 / 카드게임

**설계 원칙:**
- 물리적 조작 (카드 쥐기, 토큰 옮기기)이 개념과 연결되어야 한다
- 협동 or 경쟁 요소 포함
- 준비물은 최소화 (종이, 가위, 주사위 정도)

**결과물 구성:**
```
[게임 패키지]
- 게임명 + 한 줄 소개
- 인원 / 소요 시간 / 준비물
- 게임판/카드 레이아웃 (텍스트로 상세 묘사 또는 ASCII 다이어그램)
- 규칙북 (설치 → 턴 진행 → 승리 조건)
- 카드/토큰 목록 및 텍스트 내용
- 변형 룰 (심화 버전 / 간소화 버전)

[튜터 가이드]
- 플레이 전 브리핑 (1분)
- 플레이 중 개입 포인트 (튜터가 언제 멈추고 질문할지)
- 플레이 후 디브리핑 질문 3가지
```

---

#### 🎤 퀴즈쇼 형식

**설계 원칙:**
- 단순 O/X가 아닌 **판단력을 요구하는 질문** 위주
- 팀 대결 구조로 사회적 흥분감 유도
- "왜 그렇게 생각해?" 를 반드시 묻는 구조

**결과물 구성:**
```
[퀴즈쇼 패키지]
- 쇼 포맷 (진행 방식, 라운드 구성, 팀 구성 방법)
- 문제 세트 (총 15~20문제)
  - 라운드 1: 개념 확인 (쉬움, 5문제)
  - 라운드 2: 상황 판단 (중간, 5문제)
  - 라운드 3: 논쟁 토론 (어려움, 5문제 - 정답 없는 열린 질문)
  - 보너스: 반전 문제 (상식을 뒤집는 질문, 3문제)
- 점수판 운영 방법

[튜터 가이드]
- 진행 스크립트 (오프닝 멘트, 라운드 간 전환, 마무리)
- 논쟁 문제 퍼실리테이션 팁
```

---

### 3단계: 뇌 자극 요소 체크리스트

게임 설계 후 반드시 확인:

- [ ] **놀라움**: 아이가 예상 못한 결과를 경험하는 순간이 있는가?
- [ ] **선택의 고통**: "어떡하지?" 라는 진짜 고민이 생기는 순간이 있는가?
- [ ] **감정 이입**: 캐릭터나 역할로 몰입할 수 있는가?
- [ ] **사회성**: 친구와 비교, 협력, 경쟁하는 요소가 있는가?
- [ ] **즉각 피드백**: 내 결정의 결과를 바로 볼 수 있는가?
- [ ] **개념 역전**: 게임 안에서 "아, 그래서 이게 이렇게 되는구나!" 하는 순간이 있는가?

5개 이상 충족되면 좋은 게임이다.

---

### 4단계: 연령별 튜닝

| 요소 | 10~12세 (초고) | 13~15세 (중등) |
|------|--------------|--------------|
| 스토리 | 친근한 캐릭터, 일상적 맥락 | 현실 시나리오 (창업, 투자) |
| 규칙 복잡도 | 단순 (규칙 3개 이내) | 다층적 (변수 2~3개) |
| 경쟁 방식 | 팀 협동 + 가벼운 경쟁 | 개인 전략 + 팀 토론 |
| 추상화 수준 | 구체적 물건/돈으로 시각화 | 수치·그래프 포함 가능 |
| 시간 | 15~20분 | 25~40분 |
| 핵심 질문 | "어떻게 하면 돈이 더 많아질까?" | "왜 이 선택이 장기적으로 더 나을까?" |

## 출력 형식

항상 아래 구조로 결과물을 제공한다:

```
## 🎮 [게임 이름]
**한 줄 소개:** ...
**대상:** ...세 / **인원:** ... / **시간:** ...분

---
### 💡 이 게임이 가르치는 것
(개념과 메카닉의 연결 설명)

---
### 📦 게임 패키지
(형태에 따라 위 설계 가이드의 결과물 구성을 따름)

---
### 🧠 튜터 가이드
(브리핑 / 개입 포인트 / 디브리핑 질문)

---
### ⚡ 변형 아이디어
(심화 버전 / 간소화 버전 / 다른 개념 연결 방법)
```

---

## 품질 기준

- 개념이 게임의 **결과**에 반드시 영향을 미쳐야 한다 (장식이 아닌 메카닉)
- 튜터 없이도 아이들끼리 진행 가능해야 한다
- 게임 후 아이가 "나는 다음엔 이렇게 해야지" 라고 전략을 말할 수 있어야 한다
- 디브리핑 질문은 "어땠어?" 가 아닌 "왜 그 선택을 했어?" 수준이어야 한다
